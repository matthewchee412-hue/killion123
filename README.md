# Shrimpillion

Roblox remake of Krillion's Puffer Party ("Blowfish Blowout").

- Design: `docs/shrimpillion-design-doc.md`
- Build plan / prompts: `docs/claude-code-prompts.md`
- Instructions for Claude Code: `CLAUDE.md`

## Getting the code into Studio
Install [Rojo](https://rojo.space) (the VS Code extension or the CLI, plus the Studio plugin). Then run `rojo serve` in this folder and click Connect in the Studio plugin. Everything in `src/` syncs into the place.

Without Rojo, insert `assets/ShrimpillionAnswers.rbxmx` into ServerStorage by hand.
